# Product Brief: Job Application Tracker

## Executive Summary

**Job Application Tracker**는 여러 국내 채용 플랫폼(원티드, 사람인 등)에 흩어진 지원 현황을 한 곳에서 통합 관리하는 서비스입니다. 크롬 익스텐션으로 지원 데이터를 자동 수집하고, AI(Claude)가 JD를 요약하며, 면접 예상 질문까지 생성합니다.

구직자들은 매일 30분~1시간을 여러 플랫폼을 오가며 지원 현황을 확인하는 데 낭비합니다. 노션이나 엑셀로 수동 관리를 시도하지만, 대부분 2~3일 만에 포기합니다. 그 결과 면접에서 JD 내용을 까먹거나, 중복 지원하거나, 면접 일정을 놓치는 일이 빈번합니다.

해외에는 Huntr, Teal 같은 job tracker가 있지만 국내 플랫폼은 지원하지 않습니다. 국내에는 사실상 경쟁 솔루션이 없으며, 이는 채용 플랫폼들이 API를 제공하지 않고 DOM 구조가 복잡하기 때문입니다. 하지만 Plasmo 프레임워크와 Claude API의 성숙으로 이제 기술적으로 해결 가능한 시점이 되었습니다.

## Core Vision

### Problem Statement

구직자들은 원티드, 사람인, 잡코리아 등 여러 채용 플랫폼에 동시 지원하지만, 지원 현황을 통합 관리할 방법이 없습니다. 각 플랫폼에 개별 로그인해야 하고, 10개 이상 지원하면 어디에 뭘 지원했는지 혼란스러워집니다.

### Problem Impact

- **면접 준비 실패**: JD 내용을 까먹고 면접에서 엉뚱한 답변 → 탈락
- **중복 지원**: 같은 회사에 다시 지원해서 민망한 상황
- **일정 누락**: 서류 결과 확인 안 하다가 면접 일정 놓침
- **시간 낭비**: 플랫폼 왔다갔다하며 하루 30분~1시간 소비
- **기회 비용**: 체계적 준비 부족으로 합격 가능한 포지션에서 탈락

### Why Existing Solutions Fall Short

| 현재 대안 | 한계점 |
|-----------|--------|
| 노션/엑셀 수동 관리 | 귀찮아서 2~3일 만에 포기 |
| 플랫폼별 "지원현황" | 통합 불가, 분석 기능 없음 |
| 이메일 알림 의존 | 스팸함에 묻히거나 놓침 |
| 해외 서비스 (Huntr, Teal) | 국내 플랫폼 미지원, 한국 UX 안 맞음 |

### Proposed Solution

1. **크롬 익스텐션**으로 원티드/사람인에서 지원 데이터 자동 수집 (DOM 파싱)
2. **AI(Claude)**가 JD를 핵심 요약하고 면접 예상 질문 자동 생성
3. **통합 대시보드**에서 모든 지원 현황을 한눈에 확인
4. **스킬 트렌드 분석**으로 지원한 포지션들의 공통 요구사항 파악
5. **리마인더 알림**으로 면접일, 결과 확인 시점 놓치지 않기

### Key Differentiators

| 차별화 요소 | 경쟁 대비 장점 |
|-------------|---------------|
| **자동 수집** | 수동 입력 불필요, 지속 가능한 사용성 |
| **AI JD 요약** | 면접 5분 전 핵심만 빠르게 복습 |
| **면접 예상 질문** | JD 기반 맞춤형 준비 자료 자동 생성 |
| **국내 플랫폼 특화** | 원티드, 사람인 네이티브 지원 (해외 서비스 불가) |
| **스킬 트렌드 분석** | 내 지원 패턴에서 인사이트 도출 |
| **Why Now** | AI 품질 성숙 + 플랫폼 파편화 심화 + 개발 도구 성숙 |

## Target Users

### Primary Users

#### 메인 페르소나: 재직 중 이직 준비 개발자

**프로필**
- 경력: 2~4년차 프론트엔드/백엔드 개발자
- 상황: 현 직장 다니면서 몰래 이직 준비 (퇴근 후, 점심시간)
- 지원 빈도: 주 5~15개
- 사용 플랫폼: 원티드(메인) + 사람인 + 링크드인

**핵심 특징**
- 시간이 없음 → 효율적인 관리 도구 필요
- 여러 회사 동시 진행 → 혼란스러움
- 코딩테스트/과제 병행 → 어떤 회사가 어떤 단계인지 파악 어려움

**현재 페인포인트**
- 면접 전날 밤 JD 다시 찾아 읽으며 급하게 준비
- 노션 표 만들어두고 3일 후부터 업데이트 안 함
- 이메일 알림은 프로모션 탭에 묻힘

**원하는 상태**
> "면접 5분 전, 이 회사에 대해 완벽히 준비된 상태가 되고 싶다"

---

#### 서브 페르소나: 부트캠프 수료 신입 취준생

**프로필**
- 경력: 0년차 (부트캠프/CS 전공 졸업)
- 상황: 풀타임 구직 활동
- 지원 빈도: 주 15~30개 (적극적으로 지원)
- 사용 플랫폼: 원티드 + 사람인 + 잡코리아 + 프로그래머스

**핵심 특징**
- 지원 수가 많아서 수동 관리 불가능
- 서류 탈락 多 → 어디서 떨어졌는지도 파악 안 됨
- 경험 부족으로 면접 준비에 더 많은 시간 필요

### User Journey

| 단계 | 사용자 행동 | 감정 | 제품 역할 |
|------|------------|------|----------|
| **발견** | 개발자 커뮤니티에서 추천 봄 | 호기심 | - |
| **설치** | 크롬 익스텐션 추가 | 기대 | 간편한 설치 |
| **첫 사용** | 기존 지원내역 자동 불러오기 | 놀라움 | 자동 수집 |
| **Aha!** | JD 요약 + 예상 질문 확인 | 감동 | AI 분석 |
| **습관화** | 면접 전 대시보드 확인 | 안심 | 리마인더 |
| **충성** | 지인에게 추천 | 만족 | 지속적 가치 |

**핵심 Aha! 순간**:
1. 기존 지원 20개가 자동으로 정리된 걸 본 순간
2. JD 요약이 진짜 핵심만 뽑아주는 걸 확인했을 때
3. 면접 예상 질문이 실제로 물어볼 것 같을 때
4. 스킬 분석 "React 80%, TypeScript 70%" 인사이트를 봤을 때

**리텐션 핵심 전략**:
- 수동 입력 없이 지원할 때마다 자동 동기화
- 서류 결과 시점에 리마인더 알림
- 면접 잡히면 대시보드에서 준비

> 💡 **온보딩 목표**: 설치 후 5분 안에 가치 체험 (기존 데이터 자동 수집 → 즉각적 Aha!)
