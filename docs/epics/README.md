# Epics

이 폴더에는 Epic별 상세 문서가 저장됩니다.

## Naming Convention

`epic-{number}-{slug}.md`

예시:
- `epic-1-chrome-extension.md`
- `epic-2-backend-api.md`
- `epic-3-dashboard.md`

## Epic Document Structure

```markdown
# Epic {N}: {Title}

## Overview
{Epic 설명}

## Goals
- Goal 1
- Goal 2

## Stories
| ID | Title | Status | Priority |
|----|-------|--------|----------|
| 1.1 | ... | TODO | HIGH |

## Dependencies
{다른 Epic과의 의존성}

## Risks
{예상되는 리스크}
```
